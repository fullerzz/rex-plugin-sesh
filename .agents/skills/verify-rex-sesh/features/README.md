# Rex picker verification map

Start with [launch and doctor](../SKILL.md). Use the fixture for reproducible data and the installed Rex action for visible behavior.

| Journey | Entry points | Passing evidence |
| --- | --- | --- |
| [Catalog](catalog.md) | list, picker JSON | Default order, session IDs, host labels, unique directory names and dedupe |
| [Picker](picker.md) | action, palette, binding, CLI | Visible rows, current marker, statuses, movement and cancellation |
| [Previews](previews.md) | native command and pane modes | Selected row and matching content before and after toggling |
| [Lua and startup](configuration.md) | Lua generator, Rex config check, layer shell | Action and binding load, missing binary leaves install guidance |
| [Hosts](hosts.md) | Mac picker, host-local layer, install recipe | Correct server and binary, probe cleanup, deployment plan |

Keep a result per entry point. Missing status data, a host without sessions, or an unavailable app is a missing precondition for that journey. Capture the reason.
